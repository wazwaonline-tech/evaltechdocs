# Threat Sentinel Docs

Evaltech. Create a text logo or orange, Black and white. This is a documentation toolkit for Threat CyberSecurity Detection. This App is just a documentation App will multiple downloadable pdfs on topics of detection. The mains being pdfs of each risk of cyber attack and how to prevent them. Pdf on tools used to detect threats to sites. Pdf on legality of the role of threat detection. These are professional, well-formatted documents with long writing of a few pages.
